# TRI PLAY — Snake

Jeu Snake de la plateforme TRI PLAY (branche `dev-idriss`).

## Lancer avec Docker Compose

```bash
docker compose up --build
```

Ouvre [http://localhost:3001](http://localhost:3001)

## Développement local

```bash
npm install
npm run dev
```

## Contrôles

| Plateforme | Commandes |
|---|---|
| Ordinateur | Flèches ou ZQSD / WASD |
| Mobile / tablette | Boutons tactiles |
